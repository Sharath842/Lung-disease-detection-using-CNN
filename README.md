  Lung disease detection using deep learning

 This project is a web-based application for detecting lung diseases from medical images using a Convolutional Neural Network (CNN).  
The trained deep learning model is integrated with a Flask web application to provide an easy-to-use interface for predictions.

Technologies Used
- Python  
- TensorFlow / Keras  
- Convolutional Neural Networks (CNN)  
- Flask  
- HTML / CSS
